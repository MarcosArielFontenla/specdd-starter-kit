# ADR-0008 — Optional runtimes, mandatory real execution evidence

Status: Accepted (project owner's explicit clarification)
Date: 2026-09-04

## Decision

Warp provides architectural and functional reference, never a mandatory service,
account, terminal or paid plan. Keep the Phase 4 projection optional and out of the
portal build dependency chain. The canonical models remain authoritative.

Phase 5 may use an available agent tool under a human-operated runbook. Do not build
a generic orchestration engine to avoid vendor dependence. Preserve real issue,
generated Harness/skill consumption, approved specification, implementation,
independent review, canonical eval, telemetry and actual draft PR evidence.

Preparing fixtures, validating a graph, generating prompts or passing wizard tests
does not satisfy those execution criteria. A transcript produced by the same agent
is not an independent review; an agent cannot manufacture a human approval.

The root roadmap clarification supersedes mandatory-Warp phase wording. Phase 6 may
project evals to a supported runtime; a Warp scorer remains optional. Canonical eval
execution required by Phase 5 must not be deferred wholesale to Phase 6.

## Consequences

- No Warp purchase or login is required for local product use or Phase 5.
- An execution tool and GitHub access are still needed for the actual live pilot.
- Pause at the real human gate and at any missing external authority.
- Keep Phase 5 in progress until all linked live evidence is reviewed.
- Minimal Phase 5 run evidence is not a Phase 7 observability subsystem.
