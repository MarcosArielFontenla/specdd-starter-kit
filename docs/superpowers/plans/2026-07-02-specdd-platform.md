# SpecDD Platform Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Convert the repo to npm workspaces, extract `@specdd/ui` (single copy of Stepper + Boreal styles consumed by all three kits), and build the `platform/` portal (port 4320) with a Boreal landing and the three wizards mounted at `/specdd`, `/specforge`, `/specdeploy`.

**Architecture:** npm workspaces with a single root lockfile. `packages/ui` holds the only copy of `Stepper.jsx`/`boreal-tokens.css`/`wizard.css`; each kit imports it and deletes its local copies (zero behavior change — existing suites stay green without touching asserts). `platform/` is a fourth Astro app that imports each kit's `Wizard.jsx` via a package export and runs the three data bundlers in `predev`/`prebuild` (the bundler scripts are self-locating via `import.meta.url`, so they're invoked by path).

**Tech Stack:** npm workspaces (Node >= 20), Astro ^5.3 + React ^18.3, Playwright ^1.42. No new runtime dependencies.

**Spec:** `docs/superpowers/specs/2026-07-02-specdd-platform-design.md`

## Global Constraints

- Node `>=20.0.0`; Windows (Git Bash) + Ubuntu CI.
- **Zero behavior change in the wizards**: the existing suites (unit: specdd 5 files' tests, specforge, specdeploy 42; e2e: specdd 1, specforge 1, specdeploy 2 tests) must pass **without modifying any assert** — only import lines in kit sources may change.
- Single `package-lock.json` at the repo root; the three per-kit lockfiles are deleted.
- After migration, zero copies of `Stepper.jsx` / `boreal-tokens.css` / `wizard.css` outside `packages/ui`.
- Platform dev server port **4320** (kits keep 4321/4322/4323).
- Branding: neutral **"SpecDD Platform"**.
- Landing/portal CSS uses `p-*` class prefix (never `b-*`); all colors/spacing via Boreal tokens.
- Workspace package names (already set): `sdd-kit-wizard`, `specforge-wizard`, `specdeploy-wizard`; new: `@specdd/ui`, `specdd-platform`.
- Prompt frontmatter: `agent: agent` + `description:`.
