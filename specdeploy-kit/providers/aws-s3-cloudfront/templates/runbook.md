## Prerequisites

- AWS account; Terraform >= 1.5; AWS CLI configured locally for the one-time provision.

## 1. Provision (once)

```bash
cd infra
terraform init
terraform apply
```

Note the outputs: `distribution_id` (goes into the `CLOUDFRONT_DISTRIBUTION_ID` secret) and `cdn_domain`.
